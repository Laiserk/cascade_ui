# Cascade UI

Web UI for [Cascade](https://oxid15.github.io/cascade/en/latest/) - Small-scale MLOps library


## Installation

```bash
pip install cascade-ui
```

## How to Use

Navigate into a folder that is Cascade Workspace and run:

```bash
cascade ui
```
